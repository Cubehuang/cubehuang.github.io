1.10 list 命令遍历链表

命令概述

list 命令用于转储链表的内容。Linux内核中有两种主要链表类型：

  1. 简单单链表：结构体包含指向下一个结构体的指针
  2. 双向链表：使用嵌入的 list_head 结构体

参数详解

基本参数
  • [-o] offset：结构中”next”指针的偏移量（默认为0）
  • -e end：指定链表的明确结束地址
  • -s struct：以指定结构体格式显示每个节点
  • -S struct：类似-s，但直接从内存读取数据，速度更快
  • -x/-d：十六进制/十进制格式输出
  • -r：反向遍历（使用prev指针）
  • -B：使用Brent算法检测循环
链表起始点类型
  • start：第一个数据结构的地址
  • -H start：独立 list_head 头的地址
  • -h start：包含嵌入 list_head 的数据结构的地址
高级参数
  • -l offset：当起始地址是嵌入的链表头时，指定成员偏移量
  • -O offset：指定头节点与其他节点不同的偏移量

可以使用该命令 list_head.next 列出list链上的成员

1.11 遍历所有task 查看成员的值–foreach命令

foreach命令的含义就是：对于符合[pid | taskp | name | state | [kernel | user | gleader]条件的task执行command

  • 如果使用name过滤：使用‘name’也可以使用通配符‘name_*’

command 包括：

  • bt：列出堆栈
  • vm：列出该task的虚拟内存映射情况
  • task：列出该task的task_struct结构成员情况
  • files：列出该task 使用的文件情况
  • net：该task所使用的网络相关socket使用情况
  • set：列出该task的上下文信息，进程名，cpu，pid等信息
  • ps：列出该task的进程信息
  • sig：列出该task 信号处理相关信息
  • vtop：

  • 使用foreach+task 命令过滤活跃 -R遍历 获取rcu_read_lock_nesting 成员
